## 1. FIX (1) — THE PER-SLUG REFUSAL IS PROPERLY RESTORED

The design is better than what I asked for, and DE says why: the once-per-run read cannot know
the slugs before the book is loaded, so the predicate moved to where the slugs are known
rather than back to the call.

```python
if winner_source is None:
    winner_source = R.winner_source(required_slugs=slugs)        # unchanged
else:
    _have = winner_source.get("winners") or {}
    _missing = [s_ for s_ in slugs if s_ not in _have]
    if _missing:
        raise SettlementControlRefused(
            f"REFUSED SETTLEMENT_WINNER_MISSING_FOR_SLUG: …")
```

Checked, not read:

```
predicate equivalence   old  sorted(set(slugs) - set(winners))  -> ['c']
                        new  [s for s in slugs if s not in have] -> ['c']   equal: True
refusal token           SETTLEMENT_WINNER_MISSING_FOR_SLUG   — identical, and the message
                        writes "REFUSED " WITH the space, so the matrix's _refuse() extracts
                        the name (unlike the expected_G refusal in REVIEW 207)
coverage                default path: unchanged.  read-once path: newly covered.
```

`slugs` is already `sorted({row["slug"] for row in book["rows"]})`, so the new list-comprehension
form is order-stable and `_missing[:3]` names the same first three the old refusal did.

**Two things to carry forward, neither fatal:**

- **The exception type changed**, `RunnerRefused` → `SettlementControlRefused`. Every handler
  in this module catches `SettlementControlRefused`, so it is caught here; a caller elsewhere
  that catches `RunnerRefused` by type would now miss it. Worth one grep when the valuation
  callers are next touched.
- **No cell landed.** The routing said *"DE restores it with a cell (remove one slug's record
  from a fixture ledger → refuse by name)"*. The commit is +33/−6, all fix; `selftest()` still
  has **17 cells and neither new behaviour has one**. The message's *"DRIVEN: … a fixture
  oracle with ONE slug's record removed refuses by name while the complete one passes"* is an
  ad-hoc drive, not an instrument in the tree. **I could not run that cell because it does not
  exist**, and I could not stand in for it read-only: the refusal fires after the replay, which
  needs a book, which is heavy. What I could drive — the predicate, the token, the reachability
  of both branches — is above.

