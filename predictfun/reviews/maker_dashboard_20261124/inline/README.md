# Conversation delivery

The previous 127.0.0.1 link addresses the research machine and is not reachable from the user's chat. market-microscope.html is an inline visualization fragment for delivery in this conversation; it needs no local server or external data fetch. It contains the same verified source payload (SHA in delivery_check.json). This is a presentation adapter, not a new experiment.

The adapter uses the visualization skill's scoped root, native controls, host theme and widget-state hooks. Standard line components do not support the required mixed order segments/fills and hard execution windows, so the existing custom renderer is retained. Values, masks and economic definitions are unchanged. The event table displays the first25 visible entries; all events remain in the embedded dataset.

Final preview tested all three markets, example/arm selection, 340px width and cursor changes in a sandboxed iframe; no JS errors or horizontal overflow. Initial preview exposed unresolved canvas color tokens and widget-state echo resetting the cursor. These were corrected. A subsequent test accidentally inspected the old preview because the render tool refused to overwrite it; the refusal is kept. render3/browser3 validate the final fragment, including cursor140 after state persistence.

Use the visualization content reference with the absolute path to market-microscope.html. Do not send the localhost link again as if remotely accessible. The portable dashboard from the prior packet remains intact.
